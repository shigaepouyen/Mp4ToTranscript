# Product

## Register

product

## Users

Personal, frequent use on an Apple Silicon Mac. The existing CLI user wants to transcribe recordings without terminal commands.

## Product Purpose

Drop files or folders, choose a saved profile, run a queue, then copy or open the result. Preserve the existing CLI and local Whisper engine.

## Brand Personality

Quiet, practical, familiar. A French desktop utility with standard controls.

## Anti-references

Avoid marketing layouts, decorative dashboards, and exposing every CLI flag on the main screen.

## Design Principles

- One obvious primary action.
- Remember routine choices.
- Keep processing responsive and cancellable.
- Preserve previous exports and show recoverable errors.
- Make external text processing an explicit choice.

## Accessibility & Inclusion

Keyboard-operable controls, readable system typography, text labels for status, no decorative motion.
